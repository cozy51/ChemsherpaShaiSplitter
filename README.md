# SHAlファイル分割

SHAIファイルは、chemSHERPA-AI（成形品）で使用する製品含有化学物質情報のデータファイルです。製品・部品の構成や材質、含有化学物質などの情報が保存されています。

複数品目を含む `.shai`（ZIP）から、ZIP直下のXMLを1品目ずつの `.shai` に分割するブラウザアプリです。ファイルはサーバーや外部APIへ送信せず、ブラウザ内だけで処理します。

## 分割後のファイル名

分割後のファイル名は、XMLから読み取った**製品名**を使います（例: `SGM7J-04AFA6E.shai`）。

- 製品名を取得できなかった場合は、従来どおり製品品番をファイル名に使います。
- ファイル名に使えない文字（`\ / : * ? " < > |` と制御文字）は `_` に置き換え、100文字を超える場合は切り詰めます。
- 同じファイル名になる品目が複数ある場合は、2件目以降に `_2` / `_3` … を付けます（大文字小文字の違いのみの場合も重複として扱います）。

製品名の取得は `src/services/xmlParser.ts` が行います。chemSHERPAのスキーマはバージョンによって要素名が異なるため、特定のタグ名に決め打ちせず、次の順で探索します。

1. XMLファイル名から得た製品品番と一致する要素を見つけ、その周辺（最大4階層上まで）の名称要素を製品名として採用する。会社名・担当者名・材質名などの名称要素は除外します。
2. 見つからない場合は `ProductName` などの既知のタグ名を文書全体から探す。

## 1品目だけのファイル

読み込んだ `.shai` が1品目だけの場合は、分割しても同じ内容になるため、分割ボタンをグレーの「分割できません」にして押せないようにしています。理由はボタンの下に表示します。中身の確認やExcel出力はそのまま行えます。

## 結合モード

画面上部の「🔗 結合」に切り替えると、複数の `.shai` を1つにまとめられます（`src/MergeMode.tsx` / `src/services/shaiMerger.ts`）。

1. 結合する `.shai` を複数選択またはドロップします（「＋ ファイルを追加」であとから追加、「✕ 外す」で取り除けます）。
2. 全ファイルの品目が一覧されるので、結合する品目を選びます（2品目以上）。
3. 結合後のファイル名（初期値は `SHAI_merged_日時`）を確認して「結合」を押します。
4. 結合結果の「🔍 中身を見る」「📊 Excel」で内容を確認し、ダウンロードします。

- **同じ製品品番の品目は追加できません。** ファイルを追加したとき、すでに一覧にある品目と製品品番が同じ品目は追加せず、画面に理由を表示します（XMLの内容が異なる場合はその旨も表示します）。品目がすべて追加済みのファイルは、ファイルごと追加しません。
- XMLの中身は変更せず、ZIP直下に並べます。
- 念のため、結合時にも同じ名前で中身も同じXMLは、重複として1つだけ入れます。
- 同じ名前で中身が異なるXMLは、上書きを避けるため末尾の連番を付け替えて入れます（例: `_001.xml` → `_003.xml`）。いずれも画面に注意として表示します。

## 内容ビューア

分割前・分割後のSHAIの中身を画面上で確認できます。処理はブラウザ内だけで行います。

- **分割前**: 「読み込んだファイル」欄の「🔍 中身を見る」から、複数品目がまとまった元の `.shai`（ZIP）を開きます。ZIP内のすべてのファイルを、種類（品目XML／除外したXML／対象外）・製品名・サイズ・更新日時つきで一覧し、選んだファイルの中身を表示します（`src/ShaiViewer.tsx`）。
- **分割後**: 分割結果の「🔍 内容を確認」から、作成した `.shai` をZIPとして開き直してXMLを表示します。あわせて次の点を自動で検証します。
  - ZIP内に分割前と同じ名前のXMLが1件だけ格納されているか
  - XMLデータが分割前とバイト単位で一致しているか
  - XMLとして正しく解析できるか
  - すべての項目と値が分割前と一致しているか
  - XML内にファイル名の製品品番が含まれているか

XMLは次の3つの表示で確認できます（`src/XmlViewer.tsx` / `src/services/xmlViewer.ts`）。

- **構造ツリー**: 要素の入れ子を、属性（`name="…"` など）と値つきで折りたたみ表示します。
- **項目一覧**: 「パス・項目（`@属性名` または `(値)`）・値」の表で全項目を一覧し、キーワードで絞り込めます。
- **XMLソース**: 字下げして整形したXMLを表示します。XMLとして解析できない場合は元の文字列をそのまま表示します。

## Excel出力

XMLは読みにくいため、SHAIの内容をExcel（.xlsx）で出力できます。受け取った人が「必要な情報が入っているか」を確認する用途を想定しています（`src/services/excelExport.ts`）。

- **出力する場所**
  - 「読み込んだファイル」欄の「📊 Excel出力」: 読み込んだ `.shai` の全品目を1つのExcelにまとめます。
  - 分割結果の各ファイルの「📊 Excel」: その品目だけのExcelを出力します（ファイル名は `製品名.xlsx`）。
- **シート構成**（chemSHERPA-AI（作成支援）ツールの画面に近い並びです）
  - 製品情報: 1品目1行で、製品名・製品品番・質量・質量単位・報告単位などと「必須項目の確認」（○ すべて入力済み／× 未入力 N件）を表示します。
  - 発行者・承認者: 「項目・英語・日本語」の表です。内容が同じ品目はまとめて1つの表にします。
  - 遵法判断情報: Compliance配下の要素と属性を一覧します。管理対象基準のコード（LR01など）は名称つきで表示します。
  - 全項目: XMLのすべての属性と値です。フィルターで絞り込めます。
  - 管理対象基準: LR01〜CD01 の一覧（物質リストバージョン 2.13.00）です。
- 必須項目（ツール画面で * の付く項目。発行者・承認者は英語のみ必須）が未入力のセルは赤色で「（未入力）」と表示します。
- 印刷時はA4横・幅1ページに収まるよう設定しています。
- Excel作成用のライブラリ（exceljs）は、ボタンを押したときにだけ読み込みます。

## 開発

```bash
npm install
npm run dev
```

本番ビルドは `npm run build`、自動テストは `npm test` で実行できます。

## アイコン

`public/favicon.svg` が原本のアイコン（1枚のファイルが分割される様子を表したマーク）です。`favicon.ico` / `apple-touch-icon.png` / `icon-192.png` / `icon-512.png` はこのSVGから書き出しています。デザインを変更する場合はSVGを編集し、各PNGとICOを同じ絵柄で書き出し直してください。画面ヘッダーのマークは `src/AppMark.tsx` が同じ図形を描画しています。

## サンプルSHAlを使った確認手順

1. 次のように複数のXMLを**直下**に格納したZIPを用意し、拡張子を `.shai` に変更します。
   - `SHAI_20260724084312_100-056-024_001.xml`
   - `SHAI_20260724084312_100-060-919_002.xml`
   - `SHAI_20260724084312_100-132-760_003.xml`
   - `SHAI_20260724084312_100-221-439_004.xml`
2. `npm run dev` で表示されたURLをブラウザで開きます。
3. `.shai` をドロップするか「ファイルを選択」から開き、4品目と各製品名・製品品番が表示されることを確認します。
4. 対象を選択して「選択した品目を分割」を押します。
5. 個別ダウンロードのファイル名が製品名になっていること、`.shai` 形式であることを確認します。各ファイルをZIPとして開き、元XMLが内容を変更されず直下に1つだけ格納されていることを確認します。
6. 「すべてまとめてダウンロード」で `SHAI_split.zip` を保存し、選択したすべての `.shai` が直下にあることを確認します。
7. 「🔍 中身を見る」で元の `.shai` にZIP内の全ファイルが一覧されること、分割結果の「🔍 内容を確認」で項目と値が分割前と同じであること、分割後の検証結果がすべて ✓ になることを確認します。
8. 同じ製品名のXMLを追加した場合、2件目が `_2.shai` となることも確認できます。製品名を持たないXMLでは製品品番がファイル名になることも確認できます。

## エラー確認

- `.shai` 以外を選択する
- ZIPではないファイルの拡張子を `.shai` にする
- ZIP直下にXMLを置かない
- 想定外の名前のXMLを正常なXMLと一緒に入れる（警告のみで正常なXMLは処理できます）
